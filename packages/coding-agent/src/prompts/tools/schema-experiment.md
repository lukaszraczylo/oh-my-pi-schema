Choose the action that resolves the most uncertainty.

Register the hypotheses still standing after the record, each with the projections it predicts for the candidate actions you are weighing. The tool ranks candidates by how many hypothesis pairs each one tells apart.

Act to find out what the world is, not only to reach the goal. When several rules still fit everything recorded, the useful action is the one whose outcomes those rules disagree about. Real actions are the scarce resource, so the best experiment separates the most hypotheses in one interaction.

A candidate that every hypothesis predicts identically teaches you nothing — it will rank last. A hypothesis that predicts nothing for a candidate is listed as silent on it.

Hypotheses persist in the ledger, so a rule killed by evidence stays killed.
